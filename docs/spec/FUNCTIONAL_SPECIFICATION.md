# IntroGenerator 機能確定仕様 1.3

本書は「ユーザーが何を作れ、何を変えられ、操作後にどう見えるか」を確定する資料です。PDFの32機能を最低要件とし、元の要求に含まれる18機能群も維持します。18機能群は32機能と重なるため、合計50種類の独立機能とは数えません。

WebはScratch VMを使わず、同じsb3内の再生データと素材を独立エンジンで読みます。編集元の構造は別に保存し、出力結果から推測復元しません。

## 今回確定したこと

- 機能名だけでなく、各機能の編集操作と期待結果を定義した。
- BPM変更時の「拍固定／秒固定」と区間マーカーを保存できるようにした。
- 粒子の放射方向・角度範囲・速さ・分布を、個数や平行移動の速度と独立して保持する。
- 影・残像・線の装飾の組合せを、レイヤー順と表示範囲まで含めて定義した。
- Authoring保存形式を1.3へ更新した。再生ABIはIGRT/1.1のままで、新しい作品別My Blockは必要ない。

## 全機能に適用する編集・保存・出力条件

| 操作 | 必須の結果 |
|---|---|
| 作成・数値変更 | 項目をInspectorと必要な画面操作で変更できる。式を手書きすることを機能利用の前提にしない |
| 複製 | 内部の設定を保つ。リンクした複製と独立した複製を区別する |
| Keyframe化 | 連続値はAnimationできる。素材IDや構造の切り替えは離散操作として扱う |
| Undo/Redo | 貼り付け・Preset適用・BPM変更は一連の編集として戻せる。連続ドラッグは操作確定時に1単位とする |
| 保存・再読込 | 階層、文字、制御点、時間単位、Seed、Effect順、素材参照を保持する |
| Scene移動 | 内部の時間差を保って移動する。親と子のAnimationを別に編集できる |
| 出力 | 編集元を変更しない。近似・局所Bakeの対象と品質を出力結果に示す |
| 出力できない設定 | 対象の要素と理由を示す。機能を黙って落とした完成ファイルを作らない |
| プレビュー | 最終プレビューはCompileしたsb3相当データを独立Webエンジンで再生する |
| 編集用表示 | 制御点、選択枠、Camera範囲等は編集用表示として重ね、出力映像へ入れない |

## 境界での見え方

| 条件 | 確定した動作 |
|---|---|
| 残像の長さ0 | 残像だけを消す。本体は「本体を表示」の設定に従う |
| 残像の濃さ0／柔らかさ0 | 前者は残像を消す。後者はBlurのない過去姿勢を重ねる |
| Cameraを含む残像 | 過去の対象と過去のCameraを組み合わせた画面上の残像。現在Cameraをさらに二重適用しない |
| 対象だけの残像 | 過去の対象を現在のCameraで見る。Screen要素にはCamera由来の動きを加えない |
| 開いた曲線で表示開始が終了を越える | 線・光・端点装飾を全て非表示にする |
| 閉じた曲線の全周 | 全周を表示する。始点と終点の一致を理由に空にしない |
| 閉曲線の一部分が継ぎ目を越える | 実際の表示区間の2端にだけ装飾する。内部の継ぎ目へ余計な端点を追加しない |
| 曲線が1点へ退化 | 端点装飾を重複表示しない。向きは前フレームに依存させない |
| 「全ての影を背面」 | 指定Group内で全Shadowを先に置く。Group外の背景・文字との順序は変えない |
| 入れ子の影Group | 内側の影・本体を外側の指定passへ分類する。隔離合成の境界は1枚の子として保持し、境界内の影まで無断で外へ出さない |
| 対称配置で「向きを維持」 | 曲線と配置位置は対称になる。装飾素材の内容は鏡像にしない |
| 粒子数・色・模様の変更 | 調整対象の機能だけが変わる。現在再生Frameによって新しい乱数を引かない |
| 音声seek | 映像は任意時刻へ移動する。Scratch音声は既存仕様の先頭／生成済みcheckpointから開始し、標準機能で任意オフセット再生できると表示しない |

## 拍固定と秒固定

配置時に秒または拍を選び、その単位を保存します。単位の表示だけを切り替える操作と、位置の固定基準を変える操作を分離します。後者の切り替え時は現在の時刻を維持したまま値を変換します。

120 BPMで2拍に置いたKeyは1秒です。BPMを60へ変更すると、拍固定Keyは2秒へ動き、秒固定Keyは1秒のままです。BPM変更は対象の数値キャッシュとKey順を一括更新し、Undoで単位・値・位置をまとめて戻します。同時刻Keyの競合や開始終了の逆転が発生した場合は変更を確定せず、対象を示します。

Scene内部の拍は、そのLocal Timelineの0を基準に同じtempo mapで秒へ換算します。Sceneの移動・Time Scaleはその外側から作用します。音楽上の特定の拍へScene自体を置く場合はSceneの開始を拍固定にします。内部Keyを勝手にMain音楽の絶対拍へ固定しません。

区間マーカーは名前・位置・単位を持つ編集用の目印です。音声Eventや再生停止命令を兼ねません。マーカーへ揃える操作で、実際のKeyやSceneの位置を変更します。

## 放射Particleの編集

標準の追加状態は、全周、放射速度100論理px/Local秒、分散配置です。元のEmitterの平行速度は別項目で、初期値は0です。向きの開始角、広がる角度、放射速度、速度のばらつき、分布、発生間隔、Burst数、寿命、回転、見た目を別々に編集できます。

放射速度は角度方向の速度、従来のX/Y速度は全粒子へ加える移動です。発生時のEmitter姿勢で方向が決まり、その後Emitterを動かしても既存粒子の初期位置は移りません。Emitterへの追従を選んだ場合だけ、追従用の別設定が作用します。加速度はWorld方向か発生時のEmitter方向かを選びます。

「分散配置」は発生順を変えずに角度の偏りを抑える選択です。個数を増やしても既存粒子の方向を再配置しません。具体的な配列生成方法をユーザーの操作項目にはしません。

## 出力の選択と合格の区別

文字・曲線・Repeater・Particleは、それぞれの編集構造を残します。出力時のAsset化や局所Sequence化は編集機能を削除する理由になりません。一方、見た目を完成動画として読み込めるだけでは、元の文字や曲線を編集する機能の合格に数えません。

合格には、編集→Undo/Redo→保存再読込→Compile→Scratchと独立Webで再生→seek→重なり順の確認、が必要です。Schemaに値を保存できることと、この一連の機能が動作することは別に記録します。

この資料は機能仕様の確定版です。製品Editor、Compiler、Scratch Runtime、Web Rendererを実装済み・実機合格済みとするものではありません。検査の範囲と件数はverification内の結果ファイルを参照してください。
